# G2NRcharstats

Окно характеристик для Gothic II на Union. Плагин использует строки и значения штатного окна активного мода. Оформление взято из «Журнала экспедиции».

Положите `G2NRcharstats.vdf` в `Data/Plugins` установки Gothic II с Union. Откройте характеристики обычной игровой клавишей. По спискам можно прокручивать колесиком. `Esc` закрывает окно. В «Одиссее» можно переключить страницу штатным сочетанием или нажатием на номер страницы.

Сборка для Windows требует Visual Studio 2022 с C++ и CMake. Запустите `Build-Windows.ps1` из корня репозитория или скачайте VDF из артефактов GitHub Actions.
